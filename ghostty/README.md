# ghostty

## Core settings

| Setting | Value |
|---------|-------|
| Font | JetBrainsMono Nerd Font, size 14 |
| Theme | Kanagawa Wave |
| Background | Solid + blur |
| Option key | Treated as Alt |

## Keybinds

| Action | Keybind |
|--------|---------|
| Navigate splits | `Opt+H/J/K/L` |
| Create split left | `Opt+Shift+H` |
| Create split down | `Opt+Shift+J` |
| Create split up | `Opt+Shift+K` |
| Create split right | `Opt+Shift+L` |
| Send Escape | `Ctrl+[` |
| Alt+Enter | `Shift+Enter` |

## Eye candy

- **Cursor trail shader** — fading trail when cursor moves (`shaders/cursor.glsl`)
- Mouse hides while typing
- Minimal titlebar

## Clipboard

Terminal apps are allowed to write to system clipboard.
